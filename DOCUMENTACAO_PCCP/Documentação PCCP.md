# PCCP BackEnd

Documentação técnica do backend do sistema PCCP. **TEMOS MAIS INFORMAÇÕES NO README DO PROJETO.**

Este sistema gerencia avaliações de maturidade organizacional através dos indicadores PC (Produto Certo) e CP (Certo Produto).

# Estrutura do Projeto Backend (Java / Micronaut)

Este projeto backend foi estruturado seguindo os princípios da **Arquitetura Clean**, com o objetivo de manter o código desacoplado, testável, manutenível e com responsabilidades bem definidas entre as camadas.

As principais pastas estão localizadas em `src/main/java` e `src/main/resources`.
